# QuickTools Project Requirements

## Product requirements

- Build a fast, responsive, SEO-friendly website offering free browser-based utilities.
- Use React, Vite, JavaScript/JSX, Tailwind CSS v4, React Router DOM, and Lucide React.
- Planned tools: Image Compressor, JSON Formatter, PDF Merger, and QR Code Generator.
- Planned pages: Homepage, the four tool pages, About, Contact, and Privacy Policy.
- Process files locally in the user's browser. Never upload user files to an external server.
- Do not add a backend, database, authentication, paid APIs, Laravel, PHP, or MySQL.
- Deploy the static frontend to Vercel's free tier.

## Coding rules

- Use JavaScript and JSX; do not introduce TypeScript.
- Use Tailwind CSS v4 conventions and its Vite plugin.
- Preserve existing working files and inspect code before changing it.
- Prefer reusable React components and a clear separation between pages, components, and utilities.
- Keep dependencies necessary and scoped to project requirements.
- Provide responsive layouts, accessible controls, and clear loading, success, and error states.
- Validate user input and files, including reasonable file-size limits.
- Keep SEO titles and descriptions appropriate to each page.
- Keep all file processing client-side.
- Implement only the phase currently requested; do not start future phases automatically.
- Run the relevant build and tests after code changes and address regressions caused by those changes.
